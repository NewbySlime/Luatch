This file include a list of variables used in program configuration.

ignore_internal_data: Bool
  This parameter ignores any internal Lua variables to be shown in the program.

code_window_font: Int
  Parameter to adjust Code Window font.

inspector_font: Int
  Parameter to adjust Inspector Window font.

console_window_font: Int
  Parameter to adjust Console Window font.

ui_scale: Int
  Parameter to scale the application UI (by percentage).
